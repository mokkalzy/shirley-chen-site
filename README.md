# Shirley Chen - Marketing Portfolio

A highly tailored, professional marketing portfolio website showcasing Shirley Chen's experience, capabilities, and achievements in marketing and advertising.

## Overview

This portfolio website presents Shirley Chen as a marketing professional with 5+ years of experience in advertising, campaign coordination, and client account management. The site is designed to immediately communicate professionalism and design sensibility to visitors.

## Features

- **Hero Section**: Compelling marketing headline with clear positioning
- **Proof Strip**: Key metrics showcasing measurable impact (37M+ impressions, 700K+ users, etc.)
- **About Section**: Professional background and quick facts
- **Experience**: Case-style cards highlighting achievements at Careviv Health, Simei Media, and other organizations
- **Capabilities**: Organized skill sets across Marketing Strategy, Creative & Digital, and Analytics
- **Education**: Academic credentials from ANU and Zhejiang University
- **Contact**: Easy access to email, phone, and downloadable resume

## Design

- **Color Palette**: Cream and sage tones for a sophisticated, professional aesthetic
- **Typography**: Strong, readable type hierarchy with Inter font family
- **Motion**: Subtle fade-in animations for smooth user experience
- **Responsive**: Mobile-first design that works beautifully on all devices
- **Accessible**: Semantic HTML, proper contrast ratios, and keyboard navigation support

## Tech Stack

- **Framework**: Next.js 16 (App Router)
- **Language**: TypeScript
- **Styling**: Tailwind CSS v4
- **Deployment Ready**: Optimized production build

## Getting Started

### Prerequisites

- Node.js 18 or higher
- npm or yarn

### Installation

```bash
# Install dependencies
npm install

# Run development server
npm run dev

# Build for production
npm run build

# Start production server
npm start
```

Visit `http://localhost:3000` to view the site locally.
